### Severity guide
- **Critical:** app crashes, data loss, or users cannot log in
- **High:** a main feature gives wrong results (wrong grade, invalid data saved)
- **Medium:** feature works but with a wrong message or a workaround exists
- **Low:** cosmetic issue, typo, layout

### Bug life cycle
New → Assigned → Open → Fixed → Retest → Closed (or Reopened if the retest fails)
